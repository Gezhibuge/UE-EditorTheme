# 虚幻引擎编辑器浅色主题
虚幻引擎的编辑器主题，用于修改虚幻引擎编辑器显示的颜色
---
<img width="2560" height="1528" alt="image" src="https://github.com/user-attachments/assets/f6db314c-3a11-4fd2-bccc-593f6a9f9a9f" />
用于更改虚幻引擎的主题颜色，为虚幻引擎添加浅色（中性）主题
---
### 安装
1. 下载 josn 文件
2. 打开虚幻引擎>编辑>编辑器偏好设置
3. 找到通用-外观>当前主题>导入json文件即可
<img width="2560" height="1528" alt="image" src="https://github.com/user-attachments/assets/9b23b9b5-b7cf-401d-ad8e-a8c1f1be7808" />
4. 完成！
